# 🐘 Exercícios de PHP

Lista de exercícios desenvolvida para praticar conceitos fundamentais de PHP.

## 📌 Sobre o projeto

O projeto reúne sete exercícios desenvolvidos para praticar lógica de programação e conceitos básicos da linguagem PHP.

## 🛠️ Tecnologia

- PHP

## 🎯 Objetivo

Desenvolver conhecimentos fundamentais de programação utilizando PHP.

## 🚀 Como executar

Os exercícios podem ser executados utilizando um servidor local, como o Apache disponibilizado pelo XAMPP.
